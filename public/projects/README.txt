PROJECT PHOTOS — put your images in THIS folder.

Use these exact file names (PNG). Each one maps to a project card:

  enigma.png       -> Enigma (featured card)
  nafas.png        -> Nafas
  clientflow.png   -> ClientFlow
  swiftdrop.png    -> SwiftDrop
  app-rescue.png   -> App Rescue · Performance Overhaul

Tips:
- Recommended size: ~1200 x 800 px (landscape). They're shown with
  object-cover, so they fill the card and crop to fit nicely.
- App screenshots, mockups, or a phone-on-background render all work great.
- Until a file exists, the card automatically shows the emoji placeholder —
  nothing breaks.

Want a different name or a .jpg instead?
Edit the "image" path for that project in:  src/lib/data.js
e.g.  image: '/projects/enigma.jpg'

To REMOVE a photo and keep the emoji, set:  image: null
